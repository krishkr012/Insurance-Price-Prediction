# Insurance Price Prediction using Linear Regression

## 📌 Problem Statement

The aim of this project is to analyze the Insurance dataset and build a Linear Regression model to predict medical insurance charges based on customer information such as age, BMI, number of children, smoking status, gender, and region.

## 📊 Dataset

The dataset used in this project is **insurance.csv**, which contains the following features:

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges (Target Variable)

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🔍 Steps Performed

- Imported required libraries
- Loaded and explored the dataset (EDA)
- Checked missing values and duplicates
- Performed data visualization
- Applied Label Encoding
- Applied One-Hot Encoding
- Split the dataset into training and testing sets
- Trained a Linear Regression model
- Evaluated the model using R² Score and Adjusted R²

## 📈 Results

The model successfully predicts insurance charges based on customer attributes and achieved a strong R² Score, indicating good predictive performance.

## ✅ Conclusion

The Linear Regression model was able to identify the relationship between customer demographics, health-related factors, and insurance costs. This project demonstrates the practical application of data preprocessing, feature engineering, and regression techniques in machine learning.
